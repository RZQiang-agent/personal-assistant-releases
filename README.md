# 个人助理（macOS 菜单栏）

从微信、轻推的通知和下载文件里找出要你处理的事，记进待办，按截止时间提醒。这里只发布安装包，同时是应用内自动更新的来源。

## 能做什么

- 每 2 分钟读一次微信/轻推的新通知和新下载的文件。有人 @ 你，或者消息、文件、网页里出现你的姓名，都会进待办。
- 截止时间从原文里换算出来，写进系统「提醒事项」的「个人助理」列表，按时提醒，iPhone 上也能看到。
- ⌃⇧J：在浏览器里直接读当前网页，在其他 App 里读剪贴板。也可以右键「服务 › 发送给个人助理」，或者把文件拖进投递窗口。
- 面板里可以直接下指令，比如「#2 交了」「PMP 那个表周五前要交」「我还有哪些没弄」。

## 下载安装

1. 打开 [最新版本](https://github.com/RZQiang-agent/personal-assistant-releases/releases/latest)，下载 `PersonalAssistant-x.y.z-AppleSilicon.zip`。
2. 解压后把 `个人助理.app` 拖进「应用程序」。
3. 第一次打开如果被系统拦截，到「系统设置 › 隐私与安全性」点「仍要打开」。本包是开发者自签名，没有经过 Apple 公证。
4. 如果提示安装「命令行开发者工具」，点安装。分析部分用的是系统自带的 python3。
5. 点菜单栏图标，选右上角「…」›「设置」。填上姓名，再配置模型，最后点「测试连接」。
6. 按提示授权：
   - 通知
   - 提醒事项
   - 完全磁盘访问权限：用来读微信/轻推的通知
   - 浏览器自动化：Chrome 还要打开「显示 › 开发者 › 允许 Apple 事件中的 JavaScript」

要求：macOS 14 或更新版本，Apple 芯片 Mac。

## 模型

支持任意 OpenAI 兼容接口。默认使用本机 [oMLX](https://github.com/jundot/omlx) 上的 `qwen3.5-9b`（4bit，约 6GB 内存）。用本机 oMLX 时 Key 可以留空，会自动读取。

## 自动更新

App 启动时和之后每天会检查一次这里的新版本。确认后会自动下载、校验签名、替换并重启。正在分析内容时不会弹出提示。也可以从「…」›「检查更新…」手动检查。

## 数据与隐私

- 安装包里没有任何个人数据。待办和设置只保存在本机 `~/Library/Application Support/个人助理/`，更新不影响这些数据。
- 消息内容只会发给你在设置里填的模型地址。用本机 oMLX 时，数据不离开本机。

## 第三方组件

随包附带 [remindctl](https://github.com/openclaw/remindctl)（MIT 许可），用来读写提醒事项。许可证见 `个人助理.app/Contents/Resources/bin/remindctl-LICENSE`。
